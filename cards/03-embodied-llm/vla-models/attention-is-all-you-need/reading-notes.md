# 精读笔记：Attention Is All You Need

> 📄 对应论文：[Attention Is All You Need](https://arxiv.org/abs/1706.03762)
> 整理者：@demo
> 最后更新：2024-09-30（2026-10-05 由原精读笔记与个人理解合并为本文）

---

## 1. 问题与动机

- RNN/LSTM 是当时序列建模的标配，但必须**一个词一个词串行**计算，训练慢得难以忍受。
- 串行传递导致**长距离依赖难学**（梯度消失），机器翻译 SOTA 多年原地踏步。
- 核心疑问：序列建模一定要按顺序处理吗？能不能让每个位置直接和所有位置"对话"？

## 2. 核心方法

- **自注意力**：Q·K^T 算相似度 → softmax 归一化 → 乘 V 加权求和。每个位置一步到位看到全局，长距离依赖不再是"层层传递"。
- **多头注意力**：多组 Q/K/V 投影并行做注意力——不同头关注语法、指代、长距离依赖等不同"角度"，最后拼接。
- **位置编码**：注意力本身无序，用正弦函数给每个位置加"位置指纹"（固定函数而非可学习参数）。
- **三种注意力用法**：编码器自注意力 / 解码器掩码自注意力 / 编码-解码交叉注意力。
- **整体结构**：6 层编码器 + 6 层解码器，残差连接 + LayerNorm 训深网络，**完全抛弃 RNN/CNN**。

## 3. 关键结果

- WMT 2014 英德 28.4 BLEU、英法 41.8 BLEU，当时 SOTA（base 65M / big 213M 参数）。
- BLEU 提升本身不算巨大（1.4~1.5 点），**真正的价值是训练速度提升 5 倍以上**——快意味着能堆数据堆参数，天花板被打开。
- 8 块 P100 训 3.5 天即可复现 base 模型，门槛在当时相当低。

## 4. 批判性思考

- **O(n²) 复杂度**：显存与计算随序列长度平方增长，超长序列是硬伤（FlashAttention、Linear Attention 都在补这个洞）。
- **位置信息是人为注入的**：正弦编码外推到超长序列时效果下降；对位置极其敏感的任务不够稳。
- **归纳偏置少**：小数据场景不如 CNN/RNN，依赖大数据或预训练。
- 翻译任务句子偏短，**回避了长序列问题**——这一点后来由社区补课。

## 5. 个人收获

- **"简单反而有效"**：核心思想就是注意力 + 堆叠，但抛弃了"串行"几十年思维定式。做研究常被"大家都这么做"限制，跳出来想想"这件事非得这么做吗"往往有惊喜。
- **并行化是第一生产力**：Transformer 赢，很大程度不是效果碾压，而是能并行——同样的时间能试更多 idea。深度学习时代，速度就是一切。
- **通用架构的胜利**：一个为翻译设计的架构统治了 NLP/CV/语音/多模态，说明注意力抓住了某种本质。现在的 VLA 模型（Vision-Language-Action）本质就是用注意力关联视觉、语言、动作三种模态——对具身智能这条路是通的。
- 这篇值得反复读：第一次看结构，第二次明白多头为什么有用，第三次开始想"它为什么能 work"。
