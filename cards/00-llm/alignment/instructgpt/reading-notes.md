# 精读笔记：InstructGPT

> 📄 对应论文：[Training language models to follow instructions with human feedback](https://arxiv.org/abs/2203.02155)
> 整理者：@zeng417
> 最后更新：2026-10-05

---

## 1. 问题与动机

- GPT-3 这类语言模型的训练目标是「预测下一个词」，但用户要的是「帮我完成任务」——**优化目标与使用目标错位**，于是模型会跑题、编造、输出有害内容。
- 直接在 prompt 里写「你要有帮助、无害」作用有限（GPT-3 论文自己验证过）。
- 核心想法：把「人类觉得好」本身变成可优化的目标，用**人类反馈做强化学习（RLHF）**显式对齐。

## 2. 核心方法

- **第 1 阶段 SFT（监督微调）**：约 40 名标注员按指南，为真实用户 prompt 撰写高质量示范回答（约 1.3 万条），对 GPT-3 做监督微调。
- **第 2 阶段 RM（奖励模型训练）**：让模型对同一 prompt 生成多个候选，标注员做**两两排序**（约 3.3 万条）；训练一个输出标量分数的奖励模型，排序比较比打分一致性好得多。
- **第 3 阶段 PPO（强化学习）**：以 RM 为奖励信号，用 PPO 更新策略模型（约 3.1 万条 prompts），外加 KL 惩罚防止模型漂移到「讨好 RM 但语言崩坏」的角落。
- 数据来源强调真实任务分布（客服、写作、问答、代码等），而不是学术 NLP 数据集——这是它效果好于 FLAN/T0 的关键差异之一。

## 3. 关键结果

- 论文主结论：**1.3B InstructGPT 的输出在标注员盲评中优于 175B GPT-3**——对齐带来的"听话"收益超过 100 倍参数差距。
- 真实性提升：TruthfulQA 上说真话的比例显著提高（模型学会少编造）。
- 毒性略降，但**公开 NLP 基准有小幅回退**（对齐税），说明对齐与原始能力存在张力。
- 泛化性：对没见过的 prompt 类型、甚至非英语指令，也表现出遵循能力。

## 4. 批判性思考

- **对齐的是标注员，不是人类**：标注员群体的人口构成与偏好偏差会被系统性放大，"对齐"的前提是"谁的对齐"。
- **更自信地错误**：对齐让模型口吻更自然、更"像对的"，但校准（calibration）变差——它可能更流畅地说错话，反而更危险。
- **成本与不稳定**：标注排序昂贵；PPO 训练超参敏感、可复现性差（这也是后来 DPO 兴起的原因）。
- **通用能力小幅受损**：对齐税虽小但真实存在，说明"讨好"与"能力"在数据层面没有完全解耦。

## 5. 个人收获

- 最有价值的抽象：把「人希望模型怎样」写成**可优化的标量目标**（奖励模型），这是把主观质量工程化的一步。同样的思路可以搬到任何"好难量化"的场景（代码审查质量、PPT 美观度）。
- 「排序比打分好」是个被低估的方法论：人类不擅长给绝对分，但很擅长比大小。做数据标注方案设计时优先考虑成对比较。
- 历史定位：这篇论文 + ChatGPT 说明**对齐不是伦理装饰，而是产品可用性的前提**。"模型能力强"和"用户觉得好用"之间隔着一整套 RLHF 工程。
